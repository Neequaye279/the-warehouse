# Warehouse
Warehouse is a fun adventure game about a boy who is trapped in a warehouse and is trying to escape from security,
he must collect a number of keys to be able to escape successfully without being caught.

## How to play
- Move the boy around the warehouse (WASD or arrow keys).
- Collect all keys.
- Once the last one is collected, the exit door slides open and you win.
- If the guard catches you, you lose.
- Knock over crates and boxes to slow the guard down.

## Built with
- Unity 6.3 LTS (6000.3.14f1), Universal Render Pipeline
- C#

## Features
- Guard that chases the player using NavMesh navigation
- Physics-based movable crates
- Animated characters
- Sliding exit door with a camera cutscene on win
- Background music and pickup sound effect

## Third-party assets (not included in this repository)

- Hodaart Low Poly Character Collection 3
- Low Poly Forklift by Polygon-Park
- Crates And Barrels Pack Volume 1
- Shelves01 Pack by izanai games store


## Included starter assets
- Unity Learn Game Development pathway assets (in `Assets/_GameDev`), including Kenney animations

## How to run
1. Clone this repository.
2. Open it with Unity version 6.
3. Import the third-party assets listed above.
4. Open the warehouse scene in `Assets/Scenes` and press Play.
